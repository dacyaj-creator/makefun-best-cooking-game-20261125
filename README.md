Warung Kilat is a fast-paced Indonesian street-food kitchen game: take orders from the board, chop and cook the ingredients, assemble each dish on a plate and serve it before the ticket's timer runs out. Days get faster, combos pay more, and one burnt wok can end the rush.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
